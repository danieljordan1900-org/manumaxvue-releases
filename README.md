# GART Co - Sistema de Gestión de Cotizaciones

Aplicación de escritorio para Windows para la gestión de cotizaciones de componentes electrónicos.

## Vista previa

![Vista de Login](Login1.png)

## Características

- **Gestión de cotizaciones:** crear, editar y dar seguimiento a cotizaciones.
- **Catálogo de productos:** administrar la lista de componentes electrónicos.
- **Tableros:** armar conjuntos de productos para cotizarlos.
- **Gestión de usuarios:** administrar usuarios y roles dentro del sistema.
- **Reportes:** generar reportes en formato Excel.

## Descargar

Descarga el instalador más reciente desde **[Releases](https://github.com/danieljordan1900-org/manumaxvue-releases/releases/latest)**:

- `manumaxvue-X.Y.Z-x64-setup.exe`: instalador recomendado
- `manumaxvue-X.Y.Z-x64.msi`: instalador MSI

Una vez instalada, la app avisa sola cuando hay una versión nueva y se actualiza desde dentro.

## Tecnologías utilizadas

- **Frontend:** [Vue.js](https://vuejs.org/) 3
- **Framework de escritorio:** [Tauri](https://tauri.app/) 2
- **Backend:** [Rust](https://www.rust-lang.org/)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/) 4
- **Base de datos:** SQLite local con sincronización en la nube
